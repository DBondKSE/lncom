I thought of something classic, but with a twist for keywords:
the structure is the same as in practice repo, but each keyword has a number 0-255 attached to it - its key. 
How it is used:
: - 0,
| - 1.
:::::::: - a valid keyword, corresponding to 0 - e.g. "exit" keyword.
This way, instead of writing words, you write in binary keys (only for words, :=, {}, () stay the same)
So, is that amount of keys enough?
Example:
:|:::::: x {30}; // e.g. i64
:::::::: x;
-> Claude approved the idea and proposed memorable key values (false=0, true=1, bool=2, i32=32, i64=64, else as the bitwise inverse of if, exit=11111111), which I took as is.
